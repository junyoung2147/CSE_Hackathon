# 과목 그래프 CSV(db로 옮길 수 있음)

- 노드: `data/lecture_data/lecture_data_csv/subjects.csv` (123과목, `subject_code`가 키)
- 간선: `edges.csv`

## edges.csv (233건)
| 컬럼 | 설명 |
|---|---|
| from_code, from_name → to_code, to_name | `pre`는 선수 → 후수. `rel`은 relate, 방향이 없고 코드 순으로 적는다 |
| type | `pre` 221건(선후수), `rel` 12건(관련 과목) |
| or_with | 함께 적힌 대안 과목코드(`;` 구분). 이 중 하나만 들어도 되는 관계 (예: COMP0204 프로그래밍기초 → 자료구조의 or_with `COMP0206`) |

검증: 노드에 없는 코드, 자기 간선, 같은 과목 쌍의 중복 간선이 없고, `pre`만으로 사이클이 없다(DAG).

## 사이클 처리 결정 (2026-11-17)
- 자료구조 → 자바프로그래밍
- 컴퓨터구조, 시스템프로그래밍 → 운영체제. 컴퓨터구조와 시스템프로그래밍은 `rel`
- 네트워크프로그래밍과 시스템프로그래밍의 관계는 일단 없음
- 데이타통신 → 컴퓨터망 (학부 홈페이지에서 확인)
- 프로그래밍언어론 → 컴파일러
- 컴퓨터그래픽스와 대규모병렬컴퓨팅, 증강현실과 지능HCI는 `rel`

## 시간축 규칙 (2026-11-17)
두 과목이 함께 있는 **모든 전공** 교육과정에서 선수과목이 더 늦은 학년·학기에 있으면 `rel`로 바꾼다(9건). 한 전공에서만 반대이거나 같은 학기인 간선은 `pre`로 둔다(실제 선수 관계가 같은 학기에 있을 수 있음).
- 인공지능수학심화 – 기계학습개론·컴퓨터비전·딥러닝, 생물정보학개론 – 기계학습개론
- 컴퓨터교재연구및지도법 – 운영체제·인공지능·컴퓨터구조
- 모바일네트워크 – 사물인터넷, SW창업프로젝트 – IT지식재산권

## 전공 그래프에서 쓰는 법 (2026-11-17)
- 전공 그래프의 노드는 그 전공 `curriculum.csv`의 과목이다.
- `pre` 간선의 선수과목이 전공에 없고 `or_with`의 대안이 전공에 있으면, 대안 과목에서 선을 긋는다.
- 대체 과목(`or_with`에 추가): 데이타베이스 COMP0322 = 데이터베이스 COME0427, 글로벌 전공용으로 선형대수 → 소프트웨어수학, 알고리즘1 → 알고리즘실습, 소프트웨어공학 → SW공학및테스팅.
- COME0427은 COMP0322와 같은 과목이라 COMP0322로 들어오는 `pre` 간선을 복사해 두었다(8건).
- 이렇게 해도 전공 밖 과목(수치해석, 논리회로, 네트워크프로그래밍 등)을 거쳐야만 이어지는 관계 29건은 그대로 둔다(흐리게 표시).
