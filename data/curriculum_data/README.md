# 전공별 교육과정 CSV

## curriculum.csv (322행, 한 행 = 전공 × 과목)

| 컬럼 | 설명 |
|---|---|
| major_name | 전공 이름 (심화컴퓨팅, 첨단컴퓨팅연구, 인공지능컴퓨팅, 플랫폼SW데이터과학, 글로벌SW융합) |
| basis_year | 교육과정 기준 연도. 플랫폼·글로벌은 2025, 나머지는 2026 |
| grade | 권장 학년 |
| semester | 권장 학기 (`1학기`/`2학기`) |
| category | 교과구분. 전공마다 다름 (예: 이산수학은 심컴 `전공`, 플랫폼 `전공기반`). 플랫폼은 ABEEK 구분(`공학전공`/`전공기반`/`기본소양`) |
| course_code | 과목코드 |
| course_name_ko | 교육과정표의 과목명. 띄어쓰기 등이 시간표와 조금 다를 수 있으니 이름은 subjects.csv 쪽을 쓰는 것을 권장 |
| credits, theory_hours, lab_hours | 학점, 이론 시수, 실습 시수 |
| is_required | 전공필수 여부 (`Y`/`N`) |
| note | 원본 태그(`tag:설계`, `tag:창업`, `KNU미래설계`)와 정리할 때 옮긴 정보(`영역:첨성인기초(글쓰기) 인문교양`, `4주 현장실습`). `;`로 구분 |
