# 경북대학교 컴퓨터학부 졸업요건·교육과정 크롤러

경북대학교 컴퓨터학부([https://aicollege.knu.ac.kr](https://aicollege.knu.ac.kr)) 사이트에서 **전공별 졸업요건과 교육과정**을 읽어 CSV로 저장하는 크롤러입니다.


결과 파일 중 주요한 파일은 curriculum.csv와 graduation_requirements.csv 입니다.

- 전공 목록을 사이트 메뉴에서 자동으로 찾습니다. 전공이 추가·삭제·개명되어도 코드를 고칠 필요가 없습니다.
- 표의 열 위치가 아니라 **헤더 글자**(`교과목코드`, `과목번호`, `학점 체계` 등)로 열을 찾습니다. 열 순서나 학기 블록 수가 달라져도 동작합니다.
- 고학번 전공(`~2025학년` 등 종료된 전공)도 같은 방식으로 수집합니다.

## 대상 페이지

| URL 패턴         | 내용                                    |
| ---------------- | --------------------------------------- |
| `sub3_N_a.php` | 전공 소개 (졸업요건 표)                 |
| `sub3_N_b.php` | 교육과정 (교육과정 표, PDF/이미지 링크) |

`N`은 전공 번호입니다. 메뉴에서 "교육과정" 하위 메뉴가 있는 항목만 전공으로 인식하므로, `sub3_1`(학부 소개)은 제외됩니다.

## 설치

Python 3.8 이상이 필요합니다.

```bash
pip install requests beautifulsoup4
pip install pdfplumber   # 선택: PDF 보조 추출용 (없으면 pypdf로 대체 시도)
```

## 사용법

```bash
python cse_crawler.py --out out
```

| 옵션              | 기본값       | 설명                                                                                                 |
| ----------------- | ------------ | ---------------------------------------------------------------------------------------------------- |
| `--out`         | `out`      | 결과를 저장할 폴더                                                                                   |
| `--delay`       | `0.7`      | 요청 사이 대기 시간(초)                                                                              |
| `--probe-extra` | `3`        | 메뉴에 없는 다음 번호의 전공 페이지(`sub3_{N+1}_a.php` …)를 몇 개까지 더 확인할지                 |
| `--pdf`         | `fallback` | `off`: PDF 추출 안 함 / `fallback`: HTML 표를 못 읽은 전공만 PDF로 보완 / `all`: 모든 PDF 처리 |
| `--save-raw`    | 꺼짐         | 원본 HTML(과 받은 PDF)을 `out/raw/`에 저장. 파싱이 이상할 때 디버깅용                              |

## 출력 파일

모든 CSV는 `utf-8-sig`(BOM 포함)로 저장되어 엑셀에서 한글이 정상 표시됩니다.

### `majors.csv` — 전공 목록

| 열                                | 설명                                   |
| --------------------------------- | -------------------------------------- |
| `major_code`                    | 페이지 번호 기반 코드 (예: `sub3_2`) |
| `major_name`                    | 전공명 (괄호 표기 제거)                |
| `status_note`                   | 메뉴의 괄호 표기 (예: `~2025학년`)   |
| `valid_until`                   | `status_note`에서 읽은 종료 연도     |
| `intro_url`, `curriculum_url` | 전공 소개 / 교육과정 페이지 주소       |

### `graduation_requirements.csv` — 졸업요건

| 열                                 | 설명                                                                              |
| ---------------------------------- | --------------------------------------------------------------------------------- |
| `major_code`, `major_name`     | 전공                                                                              |
| `basis_year`                     | 표 제목의 `○○○○학년도 기준` (없으면 빈 값)                                  |
| `item`                           | 항목 (`졸업학점`, `전공`, `교양`, `그 외`, `전공필수`, `영어성적` …) |
| `condition`                      | 학번 구간·트랙 등 적용 조건 (열이 여러 개인 표에서만 채워짐)                     |
| `requirement`                    | 요건 내용                                                                         |
| `credits`, `credits_qualifier` | 요건이 학점일 때 숫자와 `이상` 여부                                             |
| `footnote_refs`, `footnotes`   | 각주 번호와 각주 내용                                                             |
| `source_url`, `crawled_at`     | 출처와 수집 시각                                                                  |

졸업학점은 항목별로 나뉘어 저장됩니다.

```
졸업학점 | 130학점 | credits=130
전공     | 72학점  | credits=72
교양     | 30학점  | credits=30
그 외    | 28학점  | credits=28
```

- `총 이수학점`은 `졸업학점`으로 통일합니다.
- `전공필수`는 학점이 아니라 과목 목록이라 `requirement`에 그대로 들어가고 `credits`는 비어 있습니다.
- 학번 구간별로 값이 다른 전공(`sub3_5`, `sub3_6`)은 구간마다 1행씩 나오고 `condition`에 구간이 들어갑니다.
- `2018~2022학년도: 24 ~ 42학점`처럼 범위가 문장으로 적힌 값은 `credits`를 비워 둡니다.

### `curriculum.csv` — 교육과정 (과목 단위)

| 열                                             | 설명                                                                                               |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `major_code`, `major_name`, `basis_year` | 전공과 기준 연도                                                                                   |
| `grade`                                      | 학년                                                                                               |
| `category`                                   | 구분 (전공, 교양, 교직 …). 구분 열이 없는 표는 표 제목                                            |
| `semester`                                   | `1학기` / `2학기`                                                                              |
| `course_code`                                | 과목코드 (`COMP0218` 형식이 아니면 비우고 `note`에 기록)                                       |
| `course_name_ko`, `course_name_en`         | 한글명 / 영문명                                                                                    |
| `credits`, `theory_hours`, `lab_hours`   | `3-2-2` 표기를 학점 / 이론 / 실습으로 분리                                                       |
| `credit_raw`                                 | 학점 체계 원문 (`2-0-4주` 등)                                                                    |
| `is_required`                                | 필수 과목이면 `Y` (`필수`·`Required` 표기 또는 굵은 글씨)                                   |
| `grading`                                    | `S/U` 등 평가 방식                                                                               |
| `note`                                       | 보조 정보: `tag:설계`, `tag:창업`, `area:첨성인기초(글쓰기)`, `code:신규`, `KNU미래설계` |
| `source_url`, `crawled_at`                 | 출처와 수집 시각                                                                                   |

한 과목이 여러 전공 교육과정에 나오므로 같은 `course_code`가 여러 행에 있을 수 있습니다.

### `curriculum_files.csv` — 교육과정 첨부파일

`major_code`, `major_name`, `year`, `title`, `url`, `source_url`, `crawled_at`.
연도 칸이 `2020~2021`이면 그대로 저장합니다.

### `curriculum_pdf.csv` — PDF 보조 추출 (`--pdf` 옵션이 `off`가 아닐 때)

`major_code`, `major_name`, `pdf_year`, `course_code`, `course_name_ko`, `course_name_en`, `credits`, `theory_hours`, `lab_hours`, `credit_raw`, `pdf_url`, `crawled_at`.

PDF는 리플릿 형태라 텍스트만 뽑으면 학기·학년·전공필수 표시가 사라집니다. 그래서 **과목코드·과목명·학점 목록**만 얻을 수 있고, 주 데이터는 항상 HTML 표(`curriculum.csv`)입니다. HTML 표가 모두 읽히면 기본 설정(`fallback`)에서는 이 파일이 비어 있는 것이 정상입니다.

## 동작 방식

1. `sub3_2_a.php`를 열어 메뉴의 `sub3_N_a.php` / `sub3_N_b.php` 링크를 모읍니다.
2. 전공 소개 페이지와 교육과정 페이지를 각각 내려받습니다.
3. 페이지의 모든 `<table>`을 rowspan/colspan을 펼친 격자로 바꾸고, 헤더 글자로 종류를 판별합니다.
   - `교과목코드`·`과목번호` 등이 있으면 **교육과정 표**
   - `졸업요건` 헤더 또는 제목이 있으면 **졸업요건 표**
   - 파일 링크가 있으면 **첨부파일 표**
4. 졸업학점 행을 항목별로 분해하고 CSV로 저장합니다.

사이트 HTML이 `<tr> 없이 <thead><th>…</th></thead>` 같은 비표준 형태이거나 `<!-- -->` 주석 안에 과거 자료가 숨어 있어도 처리합니다. 주석 안의 링크는 사이트 화면에 보이지 않는 자료이므로 **수집하지 않습니다**.

## 수집하지 않는 것

콘솔에 `분류하지 못한 표 건너뜀`으로 표시되는 표는 의도적으로 제외한 것입니다.

- 선후수 과목 표 (전공마다 형식이 달라 통일할 수 없음)
- 모집단위 표, 졸업 포트폴리오 항목, 이수체계도 등

과목별 선후수 정보는 강의계획서 데이터(`prerequisites`, `followups`)에서 `course_code`로 붙여 쓰는 편이 일관됩니다.

## 강의계획서 데이터와 함께 쓰기

교육과정 CSV와 강의계획서 CSV는 **과목코드(`course_code`)**로 조인하세요. 과목명은 `수학Ⅱ`와 `수학 II`처럼 표기가 달라 조인 키로 쓰면 안 됩니다.

- `curriculum.csv`: 어느 전공의 몇 학년 몇 학기 과목인지, 구분, 필수 여부
- 강의계획서: 실제 개설 학기, 분반, 선후수 과목 등 (해당 학년도에 개설된 과목만 포함)

교육과정에는 있지만 강의계획서에는 없는 과목이 있을 수 있습니다(해당 학기에 미개설).

## 문제 해결

| 증상                                        | 확인할 것                                                                                                                                                     |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 콘솔에 `⚠ 교육과정 표를 찾지 못했습니다` | `--save-raw`로 다시 실행해 `out/raw/sub3_N_b.html`을 확인. 헤더 이름이 `CODE_HDR` / `NAME_HDR` / `CRED_HDR`(스크립트 상단)에 없는 새 표기일 수 있음 |
| 콘솔에 `⚠ 졸업요건 표를 찾지 못했습니다` | 졸업요건 표의 제목이나 헤더에 `졸업요건`이 없는 경우. 원본 HTML 확인                                                                                        |
| `⚠ 파일 표인데 링크를 못 찾음`           | 출력된 `href` 형태를 확인하고 `is_file_link()` 조건을 조정                                                                                                |
| 새 전공이 목록에 안 나옴                    | 메뉴에 "교육과정" 하위 항목이 없으면 전공으로 인식되지 않음. `--probe-extra` 값을 늘려 보기                                                                 |
| 영문명이 비어 있음                          | 사이트에 영문명이 없는 과목일 수 있음 (예: 일부 교양 과목)                                                                                                    |
| 요청이 실패하거나 느림                      | `--delay` 값을 늘리면 서버 부담이 줄어듦 (실패 시 최대 3회 재시도)                                                                                          |

## 알려진 한계

- 사이트 레이아웃이 크게 바뀌면(표 대신 이미지·스크립트로 렌더링하는 등) 파서를 수정해야 합니다.
- 고학번 전공의 졸업요건은 페이지에 연도 표기가 없어 `basis_year`가 비어 있고, 대신 `condition` 열에 학번 구간이 들어갑니다.
- 현재 사이트가 공개한 자료만 수집합니다. 과거 학년도의 졸업요건·교육과정은 PDF/이미지 링크로만 제공되는 경우가 있고, 이미지(jpg)는 텍스트로 추출하지 않습니다.
- 이름 끝에 붙은 `설계`, `창업` 같은 꼬리표와 교양 영역 라벨은 `note`로 옮기지만, 사이트에 새 형태의 표기가 생기면 과목명에 섞여 들어갈 수 있습니다.

## 이용 시 유의

학교 사이트에 부담을 주지 않도록 기본적으로 요청 사이에 대기 시간을 둡니다. 수집한 데이터를 공개하거나 재배포할 때는 학교의 이용 약관과 저작권 정책을 확인하세요.
